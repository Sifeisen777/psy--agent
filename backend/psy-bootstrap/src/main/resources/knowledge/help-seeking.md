# 什么时候该找专业帮助

分类: crisis
来源: 心理咨询转介标准与公共心理服务渠道

大部分情绪困扰可以自愈，也有一部分需要专业介入。区分二者的关键不是"严重不严重"这种主观判断，而是几个可观察的客观指标。

## 建议寻求专业帮助的四个信号

1. **持续时间**：情绪低落、焦虑或失眠持续两周以上，且几乎每天大部分时间都存在。
2. **功能受损**：影响到了实际生活——无法上课或工作、无法维持基本作息、回避社交到影响日常。
3. **自我调节失效**：试过规律作息、运动、倾诉、放松训练，两三周后没有改善甚至加重。
4. **出现风险想法**：有自伤、自杀念头，或出现"活着没意思""我不在了别人会更好"这类想法。

满足任意一条，就值得找专业人士谈一次。不需要等到"足够严重"。

## 去哪里找

- **学校**：多数高校设有心理健康教育中心，通常对本校学生免费，可预约个体咨询
- **医院**：三甲医院心理科、精神卫生中心；需要评估是否需要药物时首选这里
- **社会机构**：具备资质的心理咨询机构，注意确认咨询师的受训背景与督导情况
- **热线**：全国心理援助热线 12356（24 小时）；北京心理危机干预中心 010-82951332

## 心理咨询和精神科的区别

| | 心理咨询 | 精神科 |
|---|---|---|
| 主要手段 | 谈话 | 评估与药物 |
| 适用 | 情绪困扰、关系问题、适应问题 | 中重度抑郁、焦虑障碍、双相、精神病性症状 |
| 资质 | 心理学/咨询相关训练 | 医学背景，执业医师 |

两者不冲突。中度以上抑郁常见做法是药物加心理咨询并行：药物改善生理基础，咨询处理心理模式。

## 第一次咨询可以期待什么

通常是 50 分钟左右，咨询师会了解你的困扰、成长经历、当前支持系统，并说明工作方式。你不需要准备"说清楚一切"，也不必担心说错话。

如果你觉得和这位咨询师不匹配，可以换人。**咨询关系本身是疗效的一部分**，不匹配不是你的问题。

## 紧急情况

如果出现明确的自伤计划、已经实施伤害、或无法保证自己安全，请立即拨打 120，或前往最近的急诊。这种时候不要独自等待，先让身边的人知道。
